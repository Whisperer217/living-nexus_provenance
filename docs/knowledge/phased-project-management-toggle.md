---
name: Phased Project Management: Toggle System with Locked Pre-generated Prompts
use_when: When managing project phases, updates, or to-do lists, especially when a structured and controlled release of tasks is desired.
---

When initiating new project phases, a **toggle system with lock** should be implemented, embedding pre-generated prompts and allowing for manual activation from an admin page. This creates an 'actionable ledger' for managing an expanding list of tasks. The user also proposes a 'MCP controller' or mini dashboard on the Living Nexus website where they can click a tab, which calls a worker that notifies Manus to fire off the next phase. The ledger and to-do list should persist across GitHub.
