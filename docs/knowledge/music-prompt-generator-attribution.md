---
name: Music Prompt Generator with Attribution
use_when: When designing or implementing a music prompt generator feature on the user's platform.
---

A prompt generator for music should be included on the user profile with a tab for a pop-up to create prompts with lyrics, output style, and name suggestions. An attribution to **MoshAIMusic** should be displayed at the bottom of the generated output. The prompt generator should be a dropdown list allowing users to choose elements and add their own blocks of information. It should include 'identify regen', an input modal for style prompts for AI music generators, and 'archive'. All archived testimony should be accessible from both dropdowns. The profiles-tied prompt generator should be located underneath the profile on the left tabs and visible on both web and mobile.
