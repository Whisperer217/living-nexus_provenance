The preferred homepage hierarchy: 'The Gates' -> 'Welcome to Living Nexus' -> 'Creator Spotlight' (highlighting active creators) -> 'Latest Manifestations' (new content) -> 'Daily Word / Daily Witness' -> 'Choose Your Journey' (Music, Books, Art, Research) -> 'The Great Archive' -> 'Creator Districts' -> 'Living Registry' -> 'Community Hall' -> 'Stewardship & Mission'.
