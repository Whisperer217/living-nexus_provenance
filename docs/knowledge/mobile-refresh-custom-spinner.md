---
name: Mobile App Refresh Feature with Custom Spinner Aesthetic
use_when: When designing or implementing a refresh mechanism for the mobile application, especially on Android devices, and when considering the visual aesthetic of loading indicators.
---

The mobile application should include a **pull-to-refresh** feature to allow users to manually refresh content. The visual spinner should aesthetically match the 'Living Nexus cosmos theme,' potentially featuring a 'comet chasing its tail' animation. This refresh functionality should be available on every page across the platform, not just the home page.
