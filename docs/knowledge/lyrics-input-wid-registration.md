---
name: Lyrics Input and WID Registration Workflow
use_when: When processing song uploads and generating WIDs, especially when lyrics are involved.
---

The lyrics input field should be moved to the **upload page**, before the WID (Witness ID) is generated. Lyrics should be submitted as part of the original upload and included in the WID registration. The lyrics on the song detail page should display the saved lyrics, not prompt for new ones after the fact.
