---
name: Download Option Workflow for Uploaded Tracks
use_when: When implementing or updating the download functionality for individual tracks or albums on the user's platform.
---

Download should be **opt-in or opt-out** for each individual track. For album or batch uploads, the default should be 'auto off' with a message prompting the user to change settings in the archive. Download options: (1) Opt out from allowing download. (2) Allow free download. (3) Allow download only if a certain amount is gifted per track. A small download icon should be present in both list and tile modes, and at the album level on a creator's main page.
