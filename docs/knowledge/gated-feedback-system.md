---
name: Gated Feedback System for Invested Creators with Trusted Moderator Routing
use_when: When designing or implementing a feedback system for the Living Nexus platform, especially concerning who can provide feedback and who receives it.
---

Only **invested creators** (not general visitors) should be able to leave feedback. This feedback should be routed to a select group of trusted founders/moderators for resolution. The system should accommodate both positive feedback (compliments) and negative feedback (issues).
