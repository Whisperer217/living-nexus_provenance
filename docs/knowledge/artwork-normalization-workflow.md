---
name: Artwork Normalization Workflow and Principles
use_when: When performing system-wide artwork normalization or processing visual assets.
---

When performing a system-wide artwork normalization pass: original assets must not be modified - only rendering metadata should be updated. The normalization should remove distortion, normalize positioning, and apply focal-based framing where possible. It is crucial to preserve previous states for rollback and to flag edge cases for creator review. All visuals need to be micronized without losing quality - trimmed, centered cut, and processed effectively. For images with faces, faces need to be centered and cropped appropriately.
