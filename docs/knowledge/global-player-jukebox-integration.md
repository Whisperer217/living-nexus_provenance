---
name: Global Player and Jukebox Integration with Live Session Linking
use_when: When designing or implementing the global player and jukebox features, especially regarding live session integration and architectural reuse.
---

The global player should be tied to the jukebox, allowing users to see a live session playing out on the global player. This integration should enable commenting from the global player, linking to a session through 'listen together' without requiring the user to be physically present in the session. The global player's UI needs to be cleaned up, specifically addressing the visibility of the comments box and lyrics. Theater view on mobile should allow scrolling, and navigation back from cinematic view to theater view and then to the global player should be functional and intuitive.
