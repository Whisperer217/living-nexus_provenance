---
name: Jukebox Playback Persistence and Information Display
use_when: When designing or implementing the jukebox feature, especially regarding playback persistence, information display, and session integration.
---

The jukebox should persist and continue playback across the site while the user is in a session. Each playing or queued item should display information such as lyrics, creator, and WID number. This functionality should allow users to view song details and interact with the session without consuming additional resources, acting as a hyperlink to the actual song playing in the background.
