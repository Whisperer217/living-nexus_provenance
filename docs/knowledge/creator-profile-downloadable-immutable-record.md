name: Creator Profile: Downloadable Immutable Record and Document Viewer
use_when: When designing or updating the creator profile section of the platform, especially concerning intellectual property management, record-keeping, and content display.
---

The creator profile should host a full **downloadable, immutable record** in an Excel sheet format, including artwork ready for copyright submittal. Additionally, the profile should link to a separate page that displays all witnessed work through a document viewer, similar to a flip book.
