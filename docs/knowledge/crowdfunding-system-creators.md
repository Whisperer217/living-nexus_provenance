---
name: Crowdfunding System for Creators: Project Page with Donation Tracker and Platform Fee
use_when: When designing or implementing a crowdfunding system for creators on the platform, especially for manuscripts or projects.
---

The platform should allow creators to upload manuscripts or projects and build dedicated project pages with video, documented processes, a 'support me' button, and a donation tracker. The platform takes a percentage (e.g., 10%) of the crowdfunded amount. A WID should be generated when a project is published. Projects should be displayed in a scrollable feed on the creator's page and in a horizontal scroll on the home screen. A '/projects' discovery page should be added, along with a 'Projects' navigation link next to 'Explore'. Progress update notifications should be sent to all donors. A 'Follow Project' button should be available for non-donors.
