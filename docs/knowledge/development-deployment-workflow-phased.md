---
name: Development and Deployment Workflow Preference: Phased Approach with Triage Procedures
use_when: When developing, fixing, or deploying features for any project, especially those involving critical user experience elements.
---

The user prefers a workflow that focuses on **fixing and deploying one solid thing at a time**: (1) Fix a single feature. (2) Test it end-to-end. (3) Deploy it. (4) Conduct an audit. (5) Proceed to the next fix. Deploying multiple features at once should be avoided. Critical functionalities must be confirmed working end-to-end before deployment. When encountering a 'loop', fall back on established doctrine. When explicitly told to **'hold'**, pause and await further instructions.
