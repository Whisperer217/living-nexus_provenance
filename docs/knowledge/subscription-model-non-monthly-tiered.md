---
name: Subscription Model Preference: Non-Monthly Terms and Tiered Access
use_when: When designing or implementing a subscription or access model for the user's content or products, especially the Academy.
---

The user has a strong preference **against standard monthly subscriptions**. Preferred models include: (1) A 'Founders' one-time payment for unlimited access with tiered pricing, (2) One-time licenses with a set number of slots, (3) 'Pay as needed' slot packages (e.g., 100, 300, 500 slots), (4) Micro slot packages (e.g., 10, 30, 50 slots).
