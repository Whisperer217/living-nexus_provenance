---
name: Agent's Proactive Enhancement of User Requests
use_when: Whenever the user sends a request or task, especially when the goal is to push the request further or add a unique element.
---

When the user sends a request, the agent should always **add something special** that aligns with or pushes the request further before proceeding with the build-out or execution. This implies a proactive and creative approach to fulfilling user requests, aiming to enhance them beyond the explicit instructions.
