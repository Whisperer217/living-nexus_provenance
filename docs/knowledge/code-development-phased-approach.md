---
name: Code Development and Feature Implementation Workflow: Phased Approach with Triage Procedures
use_when: When developing code, implementing new features, or managing code bundles across the platform, especially to prevent issues like features going 'off the rails' or causing unexpected interactions.
---

The user prefers a **phased approach** to code development and feature implementation, similar to 'triage procedures in medicine'. Before redesigning any pages, the complete Living Nexus Design System must be built, defining typography, spacing, grid, corner radii, iconography, button hierarchy, color tokens, animation language, shadows, glow treatments, border treatments, cards, forms, navigation, motion, and accessibility. Before any code refactoring, the following deliverables must be provided and approved: Current architecture map, Dependency graph, Proposed package structure, Migration roadmap, List of breaking changes, Recommended implementation order, Risk assessment, and Estimated effort for each phase.
