---
name: Batch Upload Workflow Enhancements
use_when: When designing or updating the batch upload functionality for content on the platform.
---

When implementing batch upload functionality, the user prefers the ability to select multiple items and drop them at once. The genre and original creation date fields should be brightened for better visibility. The 'Original Creation Date' field should be added to the batch fill window for mass application. When 'HAAI' is selected in batch upload, all associated sections for filling out details should be available. HAAI needs to be included in the individual upload process as well.
