# Explore scrolling and search — implementation provenance

- **Origin:** Jacob Ross reported visible jitter and lag when loading and scrolling Works on Explore on 2026-09-12, and asked for a smoother flow.
- **Starting source:** `Whisperer217/living-nexus_provenance` main `c6a803d5`; the existing Explore list, Registry `songs.exploreIndex` query, WorkListRow, global PlayerProvider, and public work visibility policy remain authoritative.
- **Observed baseline:** the live Explore page mounted 693 list rows and approximately 8,451 page buttons/links at once; its scroll region measured roughly 65,494px high. Source review found the 700-work query limit was also applied to two short horizontal discovery strips, and every row scanned the whole queue to find its playback position.
- **Change:** the main collection still loads up to 700 public works for local search and ordered playback across the returned set. Recently Witnessed and Hidden Gems now request at most 20 records each. The list initially renders 32 works, adding 32 when its sentinel approaches the shared scroll viewport, with a keyboard-accessible Show more fallback. Queue positions use a precomputed map; skipped row painting uses CSS content visibility. Search resets the visible window without removing works from the underlying response.
- **Boundaries:** no Work, WID, provenance, creator, permission, audio engine, schema, credential, or publication contract changes. Playback does not imply AI context. This is a rendering and query-size derivative of the original Explore surface, not a new Registry interpretation.
- **Verification:** TypeScript check passed; three focused Explore/layout test files passed (8/8); production build passed. The full local suite returned 617 passed, 19 failed, 1 skipped, with failures in unrelated pre-existing CSS-marker, Windows line-ending, and missing secret/database-dependent contracts. The before-state DOM count was inspected in the browser. This branch has not been deployed, so an after-state field performance measurement remains for staging review.
