# Living Nexus — UI Language Guide
## LNLS v1.0 · Section 5

This document defines exactly what users see on the platform. Every label, button, heading, and instruction must use the canonical vocabulary. Prohibited alternatives are listed for every term.

---

## Core Rule

> The platform's language is not a style choice. It is a philosophical position. Every word a user sees either reinforces the platform's doctrine or contradicts it. There is no neutral language.

---

## Navigation Labels

| Canonical | Prohibited | Reason |
|---|---|---|
| Register Work | Upload, Post, Submit, Add | Upload is a technical operation. Register is a provenance act. |
| Ingest Provenance | Upload File, Add File | Ingestion is the provenance analysis step, not a file transfer. |
| Witness Registry | Followers, Subscribers, Fans | Witnesses acknowledge a creative record. They are not subscribers. |
| My Archive | My Library, My Content, My Uploads | Archive implies preservation. Library implies consumption. |
| Manifestation Studio | Upload Studio, Create Studio | A Manifestation is the act of bringing a work into existence on the platform. |
| Keeper | AI Assistant, Chatbot, AI | The Keeper is the creator's intelligence partner, not a generic AI tool. |
| Stewardship | Mode, Category, Type | Stewardship implies ongoing responsibility, not just a selection. |
| Provenance | Metadata, Info, Details | Provenance is the human record. Metadata is technical data. |
| Testimony | Post, Update, Note, Story | Testimony is a witnessed human record. Post implies social media. |
| Session | Project, Draft, Work-in-Progress | A Session is a documented creative period with its own WID. |

## Action Labels

| Canonical | Prohibited | Reason |
|---|---|---|
| Witness | Follow, Subscribe, Like | To Witness is to acknowledge a creative record, not to subscribe to content. |
| Register | Upload, Save, Publish | Registration is the act of entering the provenance chain. |
| Verify | Check, Confirm, Validate | Verification is the act of confirming a WID against the Registry. |
| Ingest | Analyze, Scan, Process | Ingestion is the provenance analysis step. |
| Archive | Delete, Remove, Hide | Archiving preserves. Deleting destroys. |
| Disclose | Declare, Admit, Confess | Disclosure is neutral record-keeping, not an admission. |

---

## Questions the Platform Does Not Ask

| Prohibited Question | Canonical Question | Reason |
|---|---|---|
| Was AI used? | Who participated? | Participation is the correct frame. AI use is not a yes/no question. |
| Is this human-made? | What is the creation chain? | Human/AI is not binary. The chain describes participation. |
| Upload your file | Register your work | The act is registration, not file transfer. |
| Add a description | Tell the story of this work | Description is passive. Story is testimony. |
| Choose a category | Declare the domain | Domain identity is a declaration, not a categorization. |

## Status Labels

| Status | Meaning | Do Not Use |
|---|---|---|
| Registered | Work has a WID and is in the Registry | Uploaded, Saved, Published |
| Witnessed | Work has been formally acknowledged by the Registry | Verified, Confirmed, Approved |
| Archived | Work is preserved in its registered state | Deleted, Hidden, Removed |
| Disputed | Work's provenance is under review | Flagged, Reported |
| Pending | Work is in the registration queue | Processing, Loading |

---

## Authorship Labels

| Canonical | Prohibited | Reason |
|---|---|---|
| Human-Authored via AI Instrument (HAAI) | AI-Generated, AI-Made, AI-Created | HAAI describes human authorship with AI as instrument. |
| AI-Participated | AI-Generated (when human also participated) | Participation is the correct frame. |
| Creation Chain | Authorship, Credits | Chain implies sequence and relationship, not just attribution. |
| Participant | Author, Creator (when referring to AI) | AI does not author. It participates. |

## Person Labels

| Canonical | Prohibited | Reason |
|---|---|---|
| Creator | Content Creator, Artist, User | Creator is defined by the act of registration, not by content type. |
| Witness | Follower, Fan, Subscriber | Witnesses acknowledge a creative record. |
| Steward | Admin, Manager, Owner | Stewardship implies ongoing responsibility. |
